# 黄金盈亏来源拆解

已确认需求：在现有持仓功能上添加来源拆解，不重做计算、日历、金额隐藏或账户云同步。

## 交互

- 汇总预计到手仍打开全部持仓；真实盈亏数字独立打开「盈亏来源」。日历与眼睛按钮继续独立响应。
- 单笔详情内展示来源；全部持仓收益中的盈亏也可打开拆解。
- 最终盈亏只在页面顶部显示一次，再按「收益从哪里来」「哪些因素拉低收益」分组显示金额明细和分组合计。每项展开后显示计算说明和逐笔明细，列出记录名称、购入日期、克重与本项影响金额；来源遵守红涨绿跌。同名同日记录使用笔序区分，逐笔子行不使用展开箭头。单笔详情复用同样明细，盈亏数字由详情顶部展示。
- 分组标题使用无圆形底的右上/右下方向箭头，仅表达影响方向，不作为按钮。展开/收起操作仅用每项明细右侧的 chevron 表达，避免加减圆形图标造成操作误解。
- 记录标题优先使用品牌/名称；未填写时显示已知品类（金饰、金条、积存金）。未填写品牌/名称且品类为空或「其他」时，统一显示「黄金记录」，适用于持仓列表与单笔详情；存储的品类值不改动。
- 不再使用悬浮的累计瀑布条，避免把累计位置误读为该项金额。总投入与预计到手作为校验参照，直接对应「预计到手 − 总投入 = 预计盈亏」。
- 金额隐藏时不显示按正负分组、数值叙述或涨跌色，所有金额显示遮罩；大字体优先使用可换行的明细，VoiceOver读取来源与准确金额。
- 没有有效报价时不显示零盈亏。回收参数全为零时标注「尚未计入回收费用」；既有数据无法区分未设置和主动填写零，因此不声称渠道免收费用。

## 计算与数据边界

复用 GoldReturnCalculator，不添加存储字段或更改云接口。

已记录裸金单价的成本，拆为金价变化、纯度折算、购入工费、其他购入成本，再逐步应用每克回收扣减、比例折价、固定费用。

手动总价记录的裸金单价可能来自表单反推，因此合并展示「当前含金价值 − 总投入」，不据此归因工费或金价涨跌。混合组合中的这部分单独汇总，其余记录仍使用已知明细。

扣减与固定费用尊重预计到手为零的下限，不能重复扣减已耗尽的金值。已卖出只使用实际到手与实际成本；赠送显示赠送成本，不算投资亏损。

金额使用原界面的 Foundation 两位小数规则，在累计边界转换为整数分，各项差额加总严格等于最终显示盈亏。逐笔金额沿用所属项的累计边界及末笔分差对齐，逐笔加总严格等于该项；不把每笔独立舍入再累加。每个来源保留原始输入索引，只归入实际参与该项的记录，手动总价不分摊到已知成本项。正负影响抵消为零的来源也保留，展开可查看两边记录。半分钱、负值、组合和下限均需测试。
