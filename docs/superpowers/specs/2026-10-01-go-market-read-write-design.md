# Go 行情读写分离与持仓边界重构

用户要求：重构行情同步绕过 application、持仓领域模型耦合 JSON 两处问题；行情写入与读取互不依赖。

## 设计
- 查询 `GoldQuery` 仅注入 `GoldReadStore`，从数据库读取报价、分钟记录、秒级样本和日线。HTTP GET 不访问行情供应商、不写入数据库、不触发采集。不共享采集器内存状态。
- 写入 `GoldCollector` 仅注入供应商和 `GoldWriteStore`，独立采集报价（5秒）、分时（15秒）、日线（每分钟检查持久化日任务租约）。写侧不引用查询服务或读取端口，日线通过数据库幂等 upsert 避免无变化更新。
- PostgreSQL 提供独立 Reader/Writer 类型，共用持久化表，构造和方法严格分开。新增 00008 迁移保存最后报价、分时快照；仅前向新增表，不执行线上迁移。
- 行情同步查询用例负责品种校验、symbol/unit 映射；Reader 只实现一致性快照、游标与增量读取。HTTP 只协议转换及错误映射。既有 400、响应字段、游标兼容。
- 持仓 domain 不携带 JSON 标签，application 不 JSON 编码；HTTP DTO 和 PostgreSQL 存储 DTO 各自定义并转换。保持 API 和历史 JSONB 字段兼容、浮点毫秒精度、严格未知/缺失/null 字段检测、CAS、冻结与删除语义、4MiB 请求/响应上限。

## 行为
保留行情单位、延迟事件时间、真实分钟回退、不插值、20分钟窗口以最后有效行情为锚点、休市与重启数据可读。供应商失败保留最后落库值；无落库报价时查询返回内部不可用错误，后台补齐。读侧数据库错误不得被掩盖成旧缓存。没有读写分库、消息总线、事件溯源或新公开接口。

## 验证
只读 fake 没有写入/回源方法；写入 fake 没有读取方法；架构测试限制依赖与方法能力。回归测试涵盖实时窗口、延迟数据、分时失效、同步非法参数、持仓 DTO/JSONB 完整往返及限额。sqlc v1.31.1 generate、gofmt、go test ./...、go vet ./...、go build、关键模块 race。集成测试仅显式 TEST_DATABASE_URL，未配置则跳过并报告。
